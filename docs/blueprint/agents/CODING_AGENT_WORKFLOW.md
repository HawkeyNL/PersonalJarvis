# Coding Agent workflow

## Voor een sessie
1. Lees `STATUS.md`.
2. Lees `TODOS.md`.
3. Lees `STEPS.md`.
4. Lees relevante ADR's.
5. Zet gekozen taak op IN PROGRESS.

## Voor afronding
1. Formatter/lint/tests draaien.
2. Bewijs noteren.
3. Alleen volledig geaccepteerde taken afvinken.
4. Blockers en nieuwe TODO's toevoegen.
5. `STATUS.md` bijwerken.
6. Architectuurwijzigingen via ADR.

## Done betekent
Code, tests, documentatie, error handling en acceptatiecriteria zijn klaar.
