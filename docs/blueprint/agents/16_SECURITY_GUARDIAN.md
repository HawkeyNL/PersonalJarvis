# Security Guardian

## Doel

Controleert agentruns, tools, scopes, anomalieën en policyconflicten.

## Kan

- toolcall blokkeren;
- sessie intrekken;
- trading kill switch activeren;
- gevoelige output redacteren;
- incident alert genereren.

## Signalen

- onverwachte tool;
- scope escalation;
- prompt injection patroon;
- grote orderafwijking;
- herhaalde denial;
- afwijkend apparaat/IP;
- MCP-server/toolset gewijzigd;
- secrets in output.
