# Checklist — MCP-server toelaten

- [ ] Herkomst/eigenaar bekend.
- [ ] Versie vastgezet.
- [ ] Code/dependencies beoordeeld waar mogelijk.
- [ ] Tool list en schemas opgeslagen.
- [ ] Alleen benodigde tools toegestaan.
- [ ] Read/write gescheiden.
- [ ] Auth scopes minimaal.
- [ ] Geen token passthrough.
- [ ] Egress beperkt.
- [ ] Filesystem/shell standaard uit.
- [ ] Prompt-injection tests.
- [ ] Auditlogging.
- [ ] Timeout/rate limit.
- [ ] Kill/revoke procedure.
