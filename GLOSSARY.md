# Glossary

## MCP

Model Context Protocol; standard for exposing tools/resources to AI clients.

## DOM

Depth of Market; visible price levels and quantities.

## IBKR

Interactive Brokers.

## MT5

MetaTrader 5.

## LLM

Large language model.

## RAG

Retrieval-augmented generation.

## Order proposal

Immutable intended order before approval.

## Reconciliation

Comparison of local state with authoritative broker state.

## Idempotency

Same command cannot cause duplicate effect.

## Paper trading

Simulated execution environment.

## Shadow mode

Generate decisions without sending orders.

## Prop firm

Firm/program offering evaluation and funded account structures.

## Trailing drawdown

Loss threshold that may move with account high-water mark.

## Tick size

Minimum price increment.

## Tick value

Money value of one tick per contract.

## Open interest

Number of outstanding futures contracts under the source definition.

## Continuous contract

Synthetic historical series across expiries.
