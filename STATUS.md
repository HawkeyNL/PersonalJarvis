   Codex blijven privé. De resterende eigenaarstest is DNS/router/TLS en de

1. **Codex engineering-adapter (ADR-037)**: de typed
   taak- en protocolfundering, policy-gate en worktreeplanning zijn aanwezig.
   De optionele Home Node-isolatie gebruikt een aparte `jarvis-codex`-identity
   met alleen een lokale Unix-socketgroep en root-afgedwongen immutable
   worktrees. Er is nog geen listener die is ingeschakeld, toolgrant,
   credential-flow, API-route of uitvoerrecht vóór signed approval, audit en
   runtime-cancelgrenzen aantoonbaar zijn.
2. **OpenSandbox execution boundary (ADR-040)**: providerprofielen,
   artifactvalidatie en de `jarvis-policy`-gate zijn fail-closed aangelegd.
   De pinned control-plane-build bindt dynamische poorten uitsluitend op
   loopback, vereist ook op proxy-paden een API-sleutel en weigert private/
   special-use DNS-antwoorden voor dynamische egress-allowlisting. Activeer
   werkloade uitvoering nog niet vóór de Ubuntu/Kata-adversarial test.
3. **Stem/wake live valideren op macOS**: `tauri dev` herstarten (mic-fix), in Settings de stem inschrijven en verify testen; daarna `npm run setup-wakeword` en de wake-drempel (`WakeDetector.threshold`) tunen met echte audio (`onScore` logt elke stap).
4. **Spraak end-to-end valideren op device**: STT (whisper.cpp) + speaker-verify (MFCC) zijn gebouwd. `brew install cmake` (klaar), model via `scripts/fetch-whisper-model.sh` (klaar), backend met `--features speech-whisper`. Test: transcript is echt; schrijf je stem opnieuw in (nu MFCC) en **tune de verify-drempel** (`JARVIS_SPEECH_VERIFY_THRESHOLD`) met de score-readout. Blijkt MFCC niet scherp genoeg → optionele ECAPA/wespeaker-ONNX-upgrade. Daarna: console-STT (mic → server-transcript) en wake-inferentie eventueel naar een Web Worker.

Parallel blijft staan: live test Jarvis-brein (`JARVIS_LLM_API_KEY` in backend-`.env`, gesprek end-to-end), IBKR live zodra de Client Portal Gateway draait + ingelogd (paper eerst), en B — marktdata-provider (DEC-002) voor live koersen.

  onder `jarvis-api/`, de Tauri/Vue-clients onder `jarvis-app/` en de

- **Codex engineering-grenzen (ADR-037, PR #15)**: `jarvis-codex` bevat een
  typed taakstate-machine en een kleine App Server-RPC-allowlist; hij start nog
  geen proces. `jarvis-workspace` plant uitsluitend detached worktrees vanaf
  een immutable commit en `jarvis-policy` beslist de `ExecuteCode`-risico's.
  De optionele Home Node-unit blijft standaard uit: een aparte
  `jarvis-codex`-identity beheert de lokale Unix-socket en eigen
  credential-state; een root-only helper beschermt `jarvis-core` en `.git`

  signed approval direct vóór uitvoering verifiëren, auditten en annuleren;

- **OpenSandbox-grens (ADR-040)**: `jarvis-sandbox` bevat een providerinterface
  met vaste Research/Coding/Browser/DataAnalysis/Codex-profielen, egress- en
  artifactgrenzen en de bestaande `ExecuteCode`-policybeslissing. De
  OpenSandbox-adapter accepteert alleen een geauthenticeerde loopback endpoint
  en digest-gepinde profielimages; de egress-patch weigert private en
  special-use DNS-antwoorden voordat ze in de dynamische nft-allowlist komen.
  Core roept hem nog niet aan vóór de
  runtime-gate. Er is geen host-shellfallback en geen nieuwe publieke API-route.
  De oude directe Claude Code-executor is bovendien hard uitgezet, ook wanneer
  de legacy featureflag per ongeluk aanstaat.

- **MCP-server — Jarvis' read-only tools voor Claude Code (ADR-031)**: Jarvis biedt nu een **MCP-server** (`POST /mcp`) zodat Claude Code (de 4c-executor) en je eigen Claude-tooling zijn kennis kunnen **raadplegen** — `portfolio_summary`, `jarvis_status` (host/breinen/catalogus/budget) en `recent_conversations` (geheugen). **Alles alleen-lezen + eigenaar-gebonden**: geen secrets/Core, geen holdings wijzigen, geen orders, geen agent-acties. Transport is **Streamable HTTP in de bestaande api** (geen apart binary): hergebruikt de bestaande Bearer-auth (`Authed`), plain-JSON antwoorden, en **defensief protocol** — beantwoordt zowel klassieke `initialize` als `server/discover`, echoot de gevraagde `protocolVersion`, union-resultaten, notificaties → 202, onbekende methode/tool → JSON-RPC `-32601`, plus een **DNS-rebinding-guard** (niet-lokale browser-`Origin` → 403). Koppelen via `.mcp.json` (`type:"http"`, `url:http://localhost:8080/mcp`, `Authorization: Bearer <session-token>`). api 9 tests (+1 MCP), clippy schoon. Later spoor: Jarvis als MCP-**host** (externe read-only servers consumeren).
