# Master roadmap

## R0 — documentation and spikes
API access proofs, MT5 MCP inventory, IBKR paper connectivity, TopstepX/MFFU rule snapshots.

## R1 — personal core
Auth, sync, Tauri shell, chat, watchlist and read-only news.

## R2 — portfolio
IBKR read-only, reconciliation, allocator and reports.

## R3 — futures data
Contract master, quotes/trades, candles, sessions and journal.

## R4 — orderflow
Depth ingest, book builder, features, replay and UI.

## R5 — prop companion
Rule engine, dashboards, alerts and manual trading support.

## R6 — paper execution
Approvals, risk, order state machine and paper adapters.

## R7 — strategy/backtest
DSL, Rust replay, MT5 tester, metrics and promotion.

## R8 — assisted live
Tiny limits and every order confirmed.

## R9 — content engine
Trends, scripts, renders and analytics.

No fully autonomous live trading milestone is scheduled by default.
