JARVIS

Eén Jarvis. Op jouw apparaten.

Installatiebestanden worden na verificatie op deze Home Node aangeboden. Updates in de app blijven via de aangemelde Home Node-verbinding lopen.

Desktop

Private distributie wordt voorbereid. Nog geen geverifieerde download beschikbaar.

Android

Private APK-distributie wordt voorbereid. Nog geen geverifieerde download beschikbaar.

iPhone en iPad

Een goedgekeurde IPA-kandidaat vereist lokale ondertekening. Na import vervangt de mirror deze lege pagina door de beschikbare downloads.

Na installatie

Voer het HTTPS-adres van jouw Home Node in en doorloop de apparaatregistratie. Deze pagina vraagt nooit om een token, wachtwoord of privésleutel.

Deze lege template bevat geen downloadlinks. Alleen succesvol geverifieerde bestanden horen in de gegenereerde downloadindex.

Appversies gebruiken app-vX.Y.Z. Core wordt onafhankelijk bijgewerkt. Downloadbaarheid geeft geen toestemming om je Home Node te benaderen.
